# Investigation Evidence

This folder contains screenshots collected during the Wireshark network traffic investigation.

### Evidence files

- `dns-query.png` — DNS query from the local host to the DNS server.
- `dns-response.png` — DNS response containing the resolved IP address.
- `tcp-connection.png` — TCP communication over destination port 443.
- `tls-traffic.png` — TLS 1.3 application data observed between the local host and external server.
